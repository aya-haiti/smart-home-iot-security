Que se passe-t-il quand un broker MQTT n'est pas protégé ?

Cette page rejoue dans votre navigateur le laboratoire du projet : 5 objets connectés, un broker Mosquitto vulnérable (port 1883, accès anonyme) et un broker durci (TLS 1.2, mots de passe, ACL, limites). Lancez les attaques, observez le tableau de bord, puis basculez vers le broker sécurisé.

🛡️ Simulation pédagogique : aucun broker réel n'est exposé, aucune connexion réseau n'est ouverte. Le comportement reproduit les fichiers mosquitto.conf, aclfile, les capteurs Python et la règle de détection Node-RED du dépôt.

Broker sécurisé
listener 8883 0.0.0.0
tls_version tlsv1.2
allow_anonymous false
password_file /mosquitto/config/passwords
acl_file      /mosquitto/config/aclfile
max_connections 50
message_size_limit 8192
